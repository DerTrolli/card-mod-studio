# v0.11.0 release QA — working log (2026-11-10)

Raw working log of the v0.11.0 release investigation and fix round: findings
from the real-input ("click-through") QA passes on Home Assistant 2026.11
(card-mod 4.2.1 and UIX 9.0.0), the review results, and the status of each
fix. It is a log, not a polished report — entries are terse, IDs such as
`b2-01` name the QA pass that found something, and paths under `scratchpad/`
point at evidence that lived on the build machine and is not in the repo.
The user-facing summary of what changed is `CHANGELOG.md`; the plan is
`docs/V0.11_PLAN.md`.

How the passes were run: `tools/sandbox/harness/click-driver.mjs` (real
pointer and keyboard input on the real dashboard; code only for fixtures and
observation).

- With `frontend: extra_module_url: [/local/card-mod.js]`: 20/20 YAML, 19/20 storage (2 unexplained failures with Studio loaded, not reproducible in 30 more loads; 80/80 without Studio).
- Studio has no effect on the rate (2/20 with, 1/20 without; route-blocking measurements were confounded by disabled HTTP cache).
- Upstream: no release newer than 4.2.1 / 4.2.1-202604; issue #602 (styles sometimes not applied until refresh) closed without fix; repo reported unmaintained for months. README recommends extra_module_url (performance section).
- Headless Chrome on a loaded 4-core machine only — real-user rate is an inference.
