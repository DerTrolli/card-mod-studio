## 2. What the cards' own docs say about styling (checked)

- **Mushroom** README: "Help about card mod configuration is not provided in
  this repository." — no official card-mod guidance.
- **Mushroom** community styling guide (first post 2023-08-07) uses
  `mushroom-shape-icon$ .shape` with `--icon-size` / `--icon-symbol-size`,
  and `mushroom-state-info$ .container` with `--card-primary-font-size`; it
  states it is "true as of Mushroom Version 4.4.0 and Card Mod Version
  3.4.4" — **stale** against Mushroom 5.2.3 / card-mod 4.2.1.
  [Thread](https://community.home-assistant.io/t/mushroom-cards-card-mod-styling-config-guide/600472)
- **Bubble Card** README: `card_type` values `button`, `calendar`,
  `climate`, `cover`, `empty-column`, `horizontal-buttons-stack`,
  `media-player`, `pop-up`, `select`, `separator`, `sub-buttons`. It has its
  own `styles:` option — "You can add custom styles to modify the CSS of all
  cards without using card-mod" — and **Modules** (reusable styles/templates,
  "an integrated Module Store with over 100 community-made modules"). Its
  `ha-card` styling example "works on all Bubble Card types (except for the
  pop-ups)". It does not call card-mod recommended, required or conflicting.
- No official card-mod or UIX documentation on styling Mushroom or Bubble
  was found.
- No Card-Mod Studio community-forum thread or GitHub issue asking for
  Mushroom/Bubble support exists (GitHub issues checked directly; the
  roadmap's "most-requested" label has no traceable source).

## 3. Live probes (sandbox, 2026-10-27)

Rigs: HA **2026.10.4** + card-mod 4.2.1; HA 2026.10.0b0 + UIX 8.3.1.
Cards: Mushroom 5.2.3 and Bubble Card 3.4.2 (release assets).

### 3.1 Font size unlock targets — still reachable on 2026.10

| Target | Pierce path | Result (both engines) |
|---|---|---|
| Gauge value number | `ha-gauge$` → `text.value-text { font-size … !important }` | default 16px (SVG units, bbox 19); 8px → bbox 9; 30px → bbox 35 |
| Thermostat big number | `ha-state-control-climate-temperature$` → `ha-big-number$` → `.value { font-size … !important }` | default 57px; 30px applied |

Same paths as the v0.10 probes on HA 2026.8 (`docs/V0.10_PLAN.md` §2).

**Correction (2026-10-27, `pierce_check.mjs`): the gauge's font-size is not
a visible size.** The numbers above are SVG units. `ha-gauge` fits its value
into a box of its own (it rewrites the text SVG's `viewBox` from the text),
so on a real dashboard a 32px value renders at exactly the default height
(57px on screen) once HA refits — and is only clipped until then. What does
show is HA's box for the value: `.text { max-width: 55%; max-height: 40% }`
(ha-gauge's own rule, needs `!important`). Scaled ×1.25 → the number
renders 59 → 70px tall in the editor preview; ×0.5 → 30px; it stops growing
where the dial leaves no room (≈ 125–150 % depending on card width). The
thermostat's big number is plain px and behaves as measured above.

### 3.2 Mushroom and Bubble DOM

- **Mushroom classic cards** (entity, light, climate, …): `ha-card` in the
  card's own shadow root; inside it `mushroom-card` → `mushroom-state-item`
  → `mushroom-shape-icon` / `mushroom-state-info`. The bundle uses **109
  `--mush-*` variables** (e.g. `--mush-card-primary-font-size`,
  `--mush-card-primary-color`, `--mush-icon-size`, `--mush-rgb-state-light`).
- **Mushroom 5.2.3 registers 18 card types** (`window.customCards` on the
  rig): alarm-control-panel, chips, climate, cover, empty, entity, fan,
  humidifier, light, lock, media-player, number, person, select, title,
  update, vacuum, template (each `custom:mushroom-<name>-card`). Only
  entity, light, climate, template and chips have been probed.
- **Mushroom template card (v5)** is built from **HA's own tile parts**
  (`ha-tile-icon`, `ha-tile-info`), not `mushroom-shape-icon`.
- **Bubble Card** (`card_type: button`): `ha-card` present but transparent;
  visible parts are Bubble classes — `.bubble-name`,
  `.bubble-button-background`, `.bubble-main-icon-container`. The bundle uses
  **122 `--bubble-*` variables**.

### 3.3 Which style shape reaches what (identical on card-mod and UIX)

| Style written into `card_mod`/`uix` | Mushroom classic | Mushroom template | Bubble button |
|---|---|---|---|
| `ha-card { font-size: 22px }` (today's Font output) | text stays 14px | text stays 14px | text stays 13px |
| `:host { --mush-card-primary-font-size; --mush-card-primary-color; --mush-icon-size }` | ✅ text 22px red, icon 60px | ✗ | ✗ |
| `ha-card { --card-primary-font-size; --card-primary-color; --icon-size }` | ✅ same | ✗ | ✗ |
| `ha-card { --ha-tile-info-primary-font-size; --ha-tile-info-primary-color }` (Studio's tile companions) | ✗ | ✅ text 22px red | ✗ |
| `ha-card { --tile-icon-size / --ha-tile-icon-size }` | — | ✗ icon stays 48px (open question) | — |
| `ha-card { background }` | ✅ | ✅ | ✗ (transparent `ha-card`; the visible box is `.bubble-button-background`) |
| `--bubble-main-background-color` / `--bubble-button-main-background-color` on `:host` or `ha-card` | — | — | ✗ while the light is on (state colour wins) |
| `.bubble-name { font-size; color } !important` | — | — | ✅ |
| `.bubble-button-background { background-color … !important; opacity: 1 !important }` | — | — | ✅ |
| Bubble's own `styles:` key with the two rules above | — | — | ✅ both |

### 3.4 Today's Studio on these cards (module-effect audit, card-mod, HA 2026.10.4)

`module_effect_audit.mjs` with `AUDIT_EXTRA_CARDS` (new option) over
mushroom-entity, -light, -template, -climate and bubble button: **24 dead
controls** — Accent Color, Font text colour and Threshold accent/text colour
on every Mushroom card; Accent, Icon Color, Background, Border and their
Threshold twins on Bubble. The Studio currently shows **every** module on
`custom:*` cards. "Font ✅" in that audit is only the family part: the size
written as `ha-card { font-size }` does not reach Mushroom or Bubble text
(measured directly: 22px emitted, text 14px/13px).
